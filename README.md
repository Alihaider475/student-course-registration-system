## Deployment Branches

This repository contains separate branches for different deployment methods.

| Branch | Purpose |
|---|---|
| main | Base source code |
| manual-deployment | Manual deployment setup for AWS EC2 Ubuntu |
| docker-deployment | Automated deployment setup using Docker Compose |

### Clone Manual Deployment Branch

```bash
git clone -b manual-deployment https://github.com/Alihaider475/student-course-registration-system.git
