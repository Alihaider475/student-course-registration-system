## Repository Branches

This repository is organized into separate branches to clearly demonstrate different deployment approaches for the DevOps class project.

| Branch              | Purpose                                                        |
| ------------------- | -------------------------------------------------------------- |
| `main`              | Base source code of the Student Course Registration System     |
| `manual-deployment` | Version prepared for manual deployment on AWS EC2 Ubuntu       |
| `docker-deployment` | Version prepared for automated deployment using Docker Compose |

## How to Clone a Specific Branch

### Clone the Base Project

```bash
git clone https://github.com/Alihaider475/student-course-registration-system.git
```

### Clone the Manual Deployment Branch

Use this branch when following the manual deployment .

```bash
git clone -b manual-deployment https://github.com/Alihaider475/student-course-registration-system.git
```

### Clone the Docker Deployment Branch

Use this branch when following the Docker-based automated deployment.

```bash
git clone -b docker-deployment https://github.com/Alihaider475/student-course-registration-system.git
```
